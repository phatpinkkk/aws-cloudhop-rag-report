# AWS RAG Project Deployment Workshop

#### Overview

This workshop guides you through the end-to-end deployment of the AWS RAG Project. You will learn how to build offline artifacts, set up S3 storage, deploy a FastAPI backend on EC2, configure API Gateway for HTTPS access, and host the frontend on AWS Amplify.
