### Week 2 Objectives

* Understand persistent object storage using Amazon S3.
* Learn AWS identity and access management through IAM.
* Understand basic Amazon VPC networking concepts.
* Practice controlling access to AWS resources using roles, policies, and security groups.
* Understand how compute, storage, identity, and networking work together in an AWS application.

### Week 2 Achievements

* Understood the main concepts of Amazon S3 and practiced storing and retrieving objects.
* Learned how S3 permissions and access policies control cloud storage.
* Understood IAM users, roles, policies, and the principle of least privilege.
* Learned the fundamentals of VPCs, subnets, routing, and security groups.
* Understood how EC2 workloads can securely access AWS resources through IAM permissions.
* Built the storage, identity, and networking knowledge later used in the CloudHop RAG architecture.
